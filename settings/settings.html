Keyboard Shortcuts

Quick commands for hands-free control of your browsing environment.

Action Default Shortcut Description
Toggle Power Alt + Shift + E Quickly turn eye comfort mode ON or OFF
Toggle Privacy Blur Alt + Shift + B Instantly conceal or reveal the webpage contents
Cycle Visual Mode Alt + Shift + M Switch between Night, Warm, Dim, Grayscale & Original
Dismiss Privacy Veil Escape Immediately restores page view when veil is active

To customize or reassign shortcut keys, open Chrome's native shortcuts manager:

About & Security

Built with complete privacy, performance, and transparency in mind.

LumiShade — Eye Comfort, Night Mode & Privacy

Version 1.0.0 • Manifest V3 • Open & Local

100% Local Processing

No analytics, no telemetry, and no remote server calls. Your browsing history is never accessed or recorded.

Isolated Shadow DOM

Extension UI overlays run inside closed/isolated Shadow DOM, preventing interference from hostile page CSS.

Non-Medical Notice

LumiShade is designed to reduce visual brightness and provide a more comfortable viewing experience for low-light environments. It does not make medical or ophthalmological claims.
